The name is DSECT in text, code, domains and documents (said dee-sect; it reads as dissect). DSECT// is how it looks: a visual treatment for the logo and branding only (ADR-012, ratified 2026-09-23). The // is aria-hidden, so a screen reader, a search engine and a copy-paste all get DSECT.

Lockups by tier — the name is earned by external exposure

If someone outside the company will see it, it carries the name. If it is an instrument the operator drives, it gets a codename. Branded house: everything inherits DSECT by default, and no sub-brand gets its own logo; a division accent is the entire extent of its visual independence.

Tier 1 · Entity DSECT// Developmental Systems, Engineering & Computing Technologies
Tier 2 · Division DSECT//Labs Labs · research
Tier 3 · Product DSECT//Hub A plain descriptive noun: Hub, not Nexus.
Tier 4 · Instrument Nebula Codename alone, in Inter 600. No prefix, no //.
Writing the name
  • ✓ UseDSECTRunning text, code, handles, domains: dsect.net, dsect-net/…
  • ✓ UseDSECT LabsDivision: DSECT plus the discipline, as two words.
  • ✓ UseDSECT HubProduct: DSECT plus a plain descriptive noun.
  • ✕ AvoidD//SECT · D-SECT · D/SECTSuperseded by ADR-012. // is a path separator; it can't live in a hostname, package scope or shell command.
  • ✕ AvoidDSECT// in a sentenceThe // is a visual treatment, never part of the written name.
  • ✕ AvoidLabs by DSECT · DSECTLabsDivisions are named for the discipline, never restyled.
  • ✕ AvoidDSECT NebulaInstruments carry no prefix; a prefix implies an external product commitment that does not exist.
Division accents

Square swatch = identity; circle = live state. The label always names the division. Only Labs has an assigned hue — Systems and Software inherit the entity accent until an ADR assigns them one.

The cut as a system device

ADR-012 did not delete the //; it promoted it out of the name and into the system — section rules and dividers. The break is a transparent gap in the hairline, not a painted block, so it sits on any surface.
