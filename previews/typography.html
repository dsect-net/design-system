Typography

Two families, self-hosted so the hub never phones fonts.gstatic.com. Inter carries every proportional size; JetBrains Mono is reserved for data — labels, timestamps, stats, code — never for reading prose. Display sizes use clamp() so hero type scales with the viewport instead of jumping at a breakpoint.

Display heading

h1 / clamp(28px, 3.8vw, 52px) / weight 600 / letter-spacing -.035em / line-height 1.08

Display with de-emphasis

h1 em / same size, weight 300, not italic — a de-emphasized inline span

Section heading

h2 / clamp(20px, 4vw, 28px) / weight 600 / letter-spacing -.02em

Card title

h3 / 16px / weight 500 / letter-spacing -.01em / line-height 1.2

Lede paragraph — the one sentence of supporting text under a section heading, set slightly larger and looser than body copy so it reads as a lead-in, not another line of the list below it.

.text-lede / 15px / line-height 1.7 / color --fg-3

Body copy is the estate default: 14px at 1.6 line-height, color --fg-2. Everything not explicitly a heading, label or lede falls back to this.

.text-body / 14px / line-height 1.6 / color --fg-2

Small text — card descriptions, secondary copy inside a dense panel.

.text-small / 13px / line-height 1.5 / color --fg-3
