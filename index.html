DSECT//Design System
Tokens · type · components · patterns

Decompose. Then build.

The UI system the DSECT Hub ships, extracted from the running code rather than drawn as a proposal. Light by default; dark is a full parallel set, one attribute away. It is a dense operations dossier, not a marketing site: flat rectangles, mono for data, hairline borders, and colour that is never the only signal.

Principles — embodied by the code
  1. Tokens only, never literals. tokens.css declares; everything else refers.
  2. Color is never the only signal. Every state is also a label, a shape, or both.
  3. Flat rectangles, not pills. Circles mean exactly two things: avatars and live state.
  4. Mono for data, sans for prose.
  5. 44px is the touch floor, even when the control is drawn smaller.
  6. Motion always degrades, and a working indicator never freezes.
  7. One mobile nav.
  8. The name is DSECT. DSECT// is how it looks, never how it is written.
