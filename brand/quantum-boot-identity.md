# Quantum boot identity — exploration

Draft. Not a locked mark. Does not supersede ADR-012.

Codex copy: `projects/DSECT Brand/reference/Quantum Boot Identity — Exploration.md`.

## Hierarchy

| Name | Role on a boot / greeter surface |
|---|---|
| DSECT | House. Small corner mark. `DSECT//` is visual only. |
| Quantum | The system being entered. The title. Instrument, so no `DSECT` prefix and no `//`. |
| Tritium | The N5 Pro. Host line only (`tritium-linux`). Never the title. |

Palette stays the core tokens: obsidian `#0A0B0E`, signal `#E8EBF0`, cyan `#22D3EE` as the single accent, muted `#6B7484` for the host line. Labs violet and Pulsar pink stay out.

## Surfaces

1. Mark — square, readable at 16px and 512px.
2. Banner — wide lockup, mark left, word, host on the right.
3. Title — `QUANTUM`, extended geometric caps, wide tracking. No period, no slash.
4. Wallpaper — 16:9 Ubuntu netboot / greeter. Title at optical center. Login-card zone (middle-right) stays empty.

## Directions

- **A The Cut.** Q with a diagonal slash in the counter. Same gesture as the house `//`. Quietest, will not fight the wordmark.
- **B The Well.** One ring, heavier center. Quantum as the core. Risks generic "quantum startup" if it goes glossy.
- **C The Node.** Three ticks around a center (core / node / client). Honest diagram, weak favicon, too loud for a greeter.

Recommendation if a mix is wanted: A for the mark, B's emptiness for the wallpaper.

Official artwork filenames in `brand/README.md` are not used until a direction is chosen. This file is the brief, not the mark.
